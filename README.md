# NVIDIA DCF Valuation

An Excel-based financial modelling project valuing NVIDIA Corporation using historical financial statements, financial forecasts, free cash flow and discounted cash flow (DCF) analysis.

## Project Overview

The objective of this project was to build a complete DCF valuation model using publicly available NVIDIA financial information.

The model covers:

- Historical financial statement analysis
- Revenue forecasting
- Gross margin and operating expense forecasting
- Net working capital forecasting
- Free cash flow forecasting
- Weighted Average Cost of Capital (WACC)
- Terminal value calculation
- Enterprise value and equity value
- Implied share price

## Valuation Methodology

The model uses a five-year explicit forecast period from FY2027E to FY2031E.

Free cash flow is forecast using assumptions for revenue growth, gross margin, operating expenses, taxation, depreciation and amortisation, capital expenditure and working capital.

The DCF valuation then discounts forecast free cash flows using WACC and calculates a terminal value using the Gordon Growth Model.

## Key Outputs

- **WACC:** 14.4%
- **Terminal growth rate:** 3.0%
- **Implied share price:** Approximately $160 per share
- **Current share price used in the model:** $238.90
- **Implied downside:** Approximately 33%
